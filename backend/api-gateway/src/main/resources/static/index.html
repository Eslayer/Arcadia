Cómo usar el Proxy

El API Manager expone el proxy en http://localhost:8083.
Envía tus peticiones a las mismas rutas que usaba el frontend, y opcionalmente agrega el header X-API-Key: <tu-clave> para autenticación.

Ejemplos:
GET http://localhost:8083/api/usuarios → ms-usuarios (8085)
GET http://localhost:8083/api/comics → ms-comics (8081)
GET http://localhost:8083/orders → ms-ventas (8082)
